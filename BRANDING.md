# Website comparison mark

The shared website mark in `website/7of10/assets/favicon.svg` uses the exact circle and arrow geometry from the app’s `AppIcon.icon/Assets/Lens.svg` and `ComparisonArrows.svg` in PhotoCompressor. The viewBox crops the original 1024 × 1024 artboard around the lens; the paths are unchanged.

A light gradient and rim provide a consistent web appearance. This is a web SVG composition, not an export of Icon Composer’s native refractive material. The site header, closing section, comparison handle, Privacy, Support, and favicon all reference this same asset. `apple-touch-icon.png` is a 180 × 180 rasterization of the SVG on the landing page’s paper background.
